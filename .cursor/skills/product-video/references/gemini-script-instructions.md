「今回の優先訴求」が空欄の場合は、
使用可能な訴求ポイントから有効な切り口を選んでください。

■ 動画尺・ナレーション
- 完成動画は約45秒前後を想定してください。
- 各セリフは後工程で音声生成し、ナレーションとして使用します。
- 生成したナレーション音声は動画内では1.2倍速で使用します。
- 台本全体は、1.2倍速で読み上げたときに約45秒前後になることを想定してください。
- 45秒は厳密な制限ではなく目安です。
- 秒数合わせだけを目的とした不要な文章は追加しないでください。
- 45秒に合わせるために1行を長くしないでください。
- セリフ数が増えても構いません。

■ セリフの長さ
- 1セリフは1つの意味・1つの情報にしてください。
- 目安は12〜22文字程度です。
- 原則として25文字を大きく超えないでください。
- 長くなる場合はカットを分けてください。
- テロップとして一目で読める長さを優先してください。
- 一つ一つのセリフを長くしないでください。
- 一つのセリフに複数の情報を詰め込みすぎないでください。

■ 識別番号
- 商品型番、JAN、ASIN、商品コードなどの識別番号はセリフに入れないでください。
- CTAにも型番を入れないでください。
- 商品情報に型番があっても、セリフやCTAへ転記しないでください。
- ユーザーが明示的に「型番をセリフに入れてください」と指定した場合のみ例外です。

■ 台本案
- 完成台本を3〜5パターン作成してください。
- 基本は3案です。
- 明確に異なる有効な切り口がある場合のみ最大5案まで作成してください。
- 各案は単なる言い換えにしないでください。
- フック、構成、訴求の切り口を明確に変えてください。
- どの案もそのまま選択して制作へ進められる完成形にしてください。

■ セリフのトーン
- セリフは「ドパガキ」に刺さる、テンポが良く直感的な言い回しにしてください。
- TikTokで流れてきた瞬間に意味が伝わる短く強い言葉を優先してください。
- 企業広告のような堅い説明口調は避けてください。
- 長くなる場合は意味のまとまりごとに短いセリフへ分けてください。
- 実際に声に出して自然で、テロップとしても読みやすい長さにしてください。
- 同じ意味を何度も繰り返さないでください。
- 商品説明を並べるだけでなく「だから何がいいのか」がすぐ分かる言い方にしてください。

■ 冒頭
- 最初の数秒を特に重要視してください。
- 冒頭から説明を始めず、続きを見たくなるフックから入ってください。
- 問題提起、驚き、共感、疑問、使用シーンなど、案ごとに異なる入り方を検討してください。
- フックで提示した内容は動画内で回収してください。

■ シチュエーション
- 各カットについて、セリフに対応する想定シチュエーションを1つ提示してください。
- TikTokの商品動画として実際に撮影・編集しやすいシーンを想定してください。
- シチュエーションは後工程の素材選定の参考情報として使用します。
- セリフとシチュエーションを矛盾させないでください。
- 商品情報にない使用方法や性能を勝手に作らないでください。
- 同じような絵面、構図、動作が連続しないようにしてください。
- 連続するカットでは可能な範囲で、
  人物 / 商品単体 / 手元 / 使用シーン / 引き / 寄り
  など見え方に変化をつけてください。
- 同じ商品アップを連続させないでください。
- 同じ人物が同じ場所で同じ動作を繰り返す構成を避けてください。
- 同じ画角・距離・背景が続かないようにしてください。
- 映像変化だけを目的に、セリフと無関係なシーンは入れないでください。

■ セリフ固定
各セリフは後工程で、そのまま
「ナレーション原稿」と「画面上のテロップ」
として使用します。
セリフは後工程で修正する前提にしないでください。
セリフ ＝ ナレーション原稿 ＝ テロップ

■ 事実
- 提供された商品情報・訴求ポイントにない性能、効果、仕様、数値を作らないでください。
- 根拠のない断定や過度な誇張を避けてください。
- 使用すると何が便利なのか、どう役立つのかが分かる構成にしてください。
- 商品情報と訴求ポイントには F1, F2, F3... の内部IDが付いています。
- 各案は、異なるF-IDを最低3個使ってください。
- フックや汎用的な感想だけで構成しないでください。
- 最初の3カット以内に、具体的なF-IDを1カット以上入れてください。
- セリフは、付けた根拠IDの商品事実と対応させてください。
