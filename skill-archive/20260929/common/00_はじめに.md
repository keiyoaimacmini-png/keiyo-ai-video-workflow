# 商品動画スキル（共通ビュー）

GitHubを開かずに、商品動画づくりの共通ルールを読むためのフォルダです。非エンジニアの方は、まず次の順で読んでください。

1. **01**：動画づくり全体の司令塔（共通ルール）
2. **02**：素材の置き場所・使い方で迷ったときの配置ゲート
3. **03**：Geminiに台本を作ってもらうときの共通テンプレート
4. **04**：prepare → script → narration → assembly → rough-edit → delivery の工程別ルール
5. **製品ノート**：Obsidian `product-video-materials/<型番>/` にある、その型番の台本ルール・商品事実・設定

先に **01〜04** の共通ルールを読み、その後に今回の型番の製品ノートだけを読みます。製品ノートの `edit_rules` や台本ルールは、共通ルールを置き換えるものではなく、共通ルールに追加して適用します。

このフォルダは、リポジトリ内の共通スキルを読みやすいファイル名でコピーしたものです。元のリポジトリのファイルは変更していません。
