# AN-S182 Mac版ゴールデン基準 v1

このフォルダは、MacのCapCutで制作したAN-S182動画を、別PC・別Codexアカウントで同等品質に再現できるか判定するための、メディアを含まない基準データです。

## 何を固定するか

- 1080×1920、30fps、29.7秒（891フレーム）
- 10カットの順番、開始・終了フレーム、素材名、使用範囲
- 各カットで必ず映す内容と、使ってはいけない内容
- 10個の字幕の原文、タイミング、位置・装飾
- TTS「ホリデーツイスト（Holiday Twist）」、BGMなし、元動画音声ミュート
- 5個の効果音の位置と音量
- 最後の字幕「下のカートからチェックして」
- 固定書き出し設定（AI UHDオン、4K、30fps、オプティカルフローオン、100Mbps、スマートHDRオン）

## 含めないもの

動画・画像・音声、CapCutプロジェクト本体、アカウント情報、認証情報、ローカルパス、クラウド保存先は含めません。フレーム画像も、人物・車両ブランド・背景が写るため収録しません。

## 現在の判定

`acceptance.json`の判定はHOLDです。C4の`IMG_3957.MOV`とC6の`IMG_3963.MOV`および対応sidecarが現在の素材台帳で確認できず、Mac版のC5字幕がC6字幕と1フレーム重複しています。また、音声は構造のみ確認済みで、聴感評価は未実施です。固定書き出し設定はユーザー指定値を記録していますが、今回CapCutの書き出し画面を再確認したものではありません。

このHOLDは、Mac版プロジェクトを勝手に直すという意味ではありません。現状を正確に記録し、ユーザーが「現状を基準にする」か「Mac版を修正してから再取得する」かを選べるようにするものです。

## OS差の扱い

Windows側では、カット構成、素材、原文、フレーム位置、音声配置を完全一致させます。フォント描画やエンコーダー差があるため、ピクセル一致・動画ファイルのバイト一致は要求しません。文字の読みやすさ、被写体の大きさ、TikTok表示領域との干渉、TTS/SFXの聞こえ方は人が最終確認します。

## 検証

リポジトリ直下で次を実行します。

```bash
python3 scripts/verify_golden_baseline.py
python3 scripts/verify_package.py
python3 -m unittest discover -s tests -v
```

基準の採用、GitHubへの反映、タグ作成は別の承認事項です。このローカル版は、承認されるまで配布版ではありません。

検証器が`PASS_GOLDEN_BASELINE status=HOLD`を返しても、合格したのは基準ファイルの完全性だけです。上記HOLDの解消、ユーザーによる基準採用、Windowsでの映像・音声比較、書き出し・公開の承認は別工程です。
